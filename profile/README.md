# DeepCode Lab

Making AI-assisted programming accessible to everyone.

## About Us

DeepCode Lab is an open-source organization dedicated to **democratizing AI-assisted programming**.

Our goal: to make the power of AI-assisted programming available to every developer — whether you come from a large team or work solo, whether you use commercial tools, open-source models, or your own workflows, you will find something useful here.

## What We Do

- **Tools & Scaffolds**: open-source tools, templates, and scaffolds for AI-assisted development, ready to use out of the box
- **Methods & Best Practices**: playbooks for AI-assisted workflows, prompt engineering, code review, and safe usage
- **Education & Community**: lowering the learning curve so more developers can write code efficiently and responsibly with AI

## Get Involved

- Open issues and share feedback in our repositories
- Submit pull requests to improve our code and docs
